# Spec 007: Onboarding for any owner, and the test runner

## Requirements
- FR-007-01: A new owner can set up a workspace in under 15 minutes: name, upload files, confirm labels, clients and suppliers, rules, connect agents.
- FR-007-02: The agent instruction and outbox address are shown with a copy button.
- FR-007-03: The test runner replays S1 to S9 and a clean set of about 20 ordinary actions, and scores decision, rules and evidence per scenario.
- FR-007-04: The suite re-runs whenever the rules change.

## Acceptance
- A fresh workspace is set up end to end within 15 minutes.
- The runner reports per-scenario results and the false-block rate on the clean set.
